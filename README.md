# 声词 SonoLex

超声、兽医与产品研发专业英语学习应用。当前版本：1.3。

- 420 个英中专业词条，9 本分类词库与 1 本共享进度的合并词本。
- 记忆卡片、系统英语朗读、拼写练习、收藏、间隔复习与每日复习目标。
- 支持导入 CSV、导出与恢复 JSON 备份。
- iPhone 可通过 Safari 添加到主屏幕；首次联网缓存后可离线学习。
- 学习数据保存在当前设备浏览器中，不包含跨设备云同步。

## 开启手机访问

仓库 Settings → Pages → Source 选择 Deploy from a branch → Branch 选择 main → Folder 选择 / (root) → Save。

发布成功后，以 Pages 设置页面显示的网址为准；本项目的默认网址格式为 https://mengxinlin.github.io/sonolex/。

iPhone：Safari 打开网站 → 分享 → 添加到主屏幕 → 如有“作为网页 App 打开”开关则打开 → 添加。

词库主题参考及原创释义说明见应用“我的设置”。本应用用于专业英语学习。
